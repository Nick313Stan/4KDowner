4KDowner third-party notices

This portable package bundles runtime dependencies so the application can run
without a separate development environment.

Included components:
- raylib: used as a static application dependency at build time.
- tinyfiledialogs: used as a static/source dependency at build time.
- FFmpeg: bundled in 4kdowner.shared/packages/ffmpeg. See its bundled LICENSE.
- yt-dlp / ytdown Python environment: bundled in 4kdowner.shared/packages/ytdown.
- Python packages inside the bundled virtual environment retain their own licenses.
- Inter font: bundled in assets/fonts.

This file is a packaging notice, not a replacement for upstream license files.
